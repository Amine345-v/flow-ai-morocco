Le studio ne remplace pas les experts. Il orchestre leur travail.

Les fichiers `.flow` décrivent la gouvernance. Les connecteurs Python, JavaScript ou API réalisent les opérations concrètes.

01 / COORDONNER

Des équipes bornées

Surveyor, architect et evaluator possèdent chacun un verbe professionnel : Search, Try ou Judge.

02 / DISTILLER

Des handovers nets

Un report devient le seul état utile transmis au checkpoint suivant. Le bruit ne traverse pas le pipeline.

03 / REVENIR

Une boucle contrôlée

Si l’audit détecte une dérive, `flow.back_to` renvoie le travail vers l’étape qui doit être corrigée.
